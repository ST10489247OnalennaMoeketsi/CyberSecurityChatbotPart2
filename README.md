# Project Overview

The CyberSecurity Awareness Bot is a Windows Forms chatbot application developed in C#. The purpose of the chatbot is to educate users about cybersecurity threats and safe online practices in an interactive and user-friendly way.

This Part 2 version expands on the Part 1 console application by introducing a graphical user interface (GUI), memory and recall functionality, randomised responses, sentiment detection, and improved conversational flow.

The chatbot allows users to ask questions about:

* Password safety
* Phishing scams
* Safe browsing
* Online scams
* Cybersecurity awareness

---

# Features Implemented

## GUI Interface

* Windows Forms graphical user interface
* Interactive chatbot layout
* User-friendly design with colours and labels
* Conversation display area
* Input textbox and send button

## Cybersecurity Assistance

The chatbot provides information and tips related to:

* Strong passwords
* Phishing attacks
* Safe internet browsing
* Scam awareness

## Randomised Responses

The chatbot uses lists and random selection to provide different responses for similar questions, making conversations feel more natural.

## Memory and Recall

The chatbot remembers previous discussion topics and can provide additional information when users ask for more details.

## Sentiment Detection

The chatbot can recognise emotional words such as:

* worried
* frustrated
* curious

and responds appropriately.

## Error Handling

The application validates user input and handles invalid or empty messages correctly.

## Voice Greeting

The application includes a simulated voice greeting feature using a sound file.
